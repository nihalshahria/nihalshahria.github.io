03 / highlights

Career highlights

A look at some of the systems I've designed and built.

Webhook system

Designed and built end to end on my own. Customers register webhooks for the events they care about, and every event reaches them reliably.

01

Registration & management

Customers register multiple webhooks and subscribe each one to different events.

02

Event delivery

When an event fires, it is sent to every webhook subscribed to it.

03

Automatic & manual retries

Failed deliveries are retried automatically, and customers can also retry them manually, so a short outage on their side loses nothing.

State machines for critical flows

I added state machines to customer onboarding and transaction flows, so the next step from any state is always defined.

01

Deterministic

Every state has a fixed set of next steps, so the flow never has to guess.

02

Rules enforced

Invalid transitions are rejected, so a flow can't skip a step or break a rule.

03

Safe retries

Because each state is explicit, a failed step can be retried without side effects.

Web3 abstraction service

Designed and built on my own. Other services send it a simple request and get back reliable, idempotent transactions on EVM, SVM and TVM chains. It puts correctness before speed.

Wallet provider integrations

Integrated Circle, Privy and Fireblocks, using their wallet and transaction APIs.

02

Direct chain access

Raw transactions over RPC (QuickNode and other providers): create and broadcast, then monitor the chain for status updates.

A simulation API that dry-runs raw transactions on EVM and SVM chains before they are sent.

Gas estimation

A gas estimation API for EVM, SVM and TVM chains, so fees are known up front.
